# 대지 현황 분석 skill

주소와 계획 용도를 받아 **근거가 추적되는 현황·법규·규모검토 HTML**을 만든다. 상봉동 결과는 표현·분석의 예시다. 예시의 면적, 용도지역, 3m 후퇴, 960%, 80m, 299세대, 법령 기준일을 다른 대상지에 승계하지 않는다.

## 입력과 착수

- 주소를 시·군·구까지 식별하고 법정동·지번·PNU를 대조한다. 동명·복수필지가 모호하면 그 부분만 질문한다.
- 계획 용도, 사업대지 구성, 신축/증축/용도변경/기존 건물 활용, 규모 목표를 확인한다. 미정인 선택사항은 합리적인 비교 가정으로 명시하고 진행한다.
- 사용할 `.env` 위치는 작업 폴더에서 확인한다. 파일 내용이나 키 값을 대화에 출력하지 않는다. 공유받은 사용자는 자신의 `VWORLD_KEY`, `DATA_GO_KR_KEY`를 사용한다. 키가 없으면 공개 웹 조사를 진행하고 필요한 키만 요청한다.
- 현재 건축물·사용승인부터 확인한다. 건물이 있는 필지를 나대지라고 가정하지 않는다.

## 작업 순서

1. **작업 케이스 생성**: `python3 scripts/init_case.py --out <새폴더> --address '<주소>'`. 기존 결과를 덮어쓰지 않는다. 생성된 `case.json`에 확인한 PNU·중심좌표·용도·조회일을 기록한다.
2. **공식 자료 수집**: [data-sources.md](references/data-sources.md)를 따라 공공데이터포털 대장·허가, 브이월드 필지·토지특성·규제, 토지이음 주소 일치 열람을 대조한다. 선택적으로 `scripts/collect_public.py --case <case.json> --env <env파일>`을 사용한다. 수집기는 원자료를 저장할 뿐 면적·법규의 최종 판단을 하지 않는다.
3. **지구단위계획 조사와 사용자 요청**: 아래 의무 절차 및 [district-plan.md](references/district-plan.md)를 적용한다. 고시, 결정조서, 결정도, 시행지침, 누적 변경을 각각 관리한다.
4. **분석**: [analysis-rules.md](references/analysis-rules.md)에 따라 사실/계산/가정/미확인을 나누고 최신 법령·조례·개별 고시를 확인한다. 분모가 되는 대지면적과 용적률 산정 연면적을 분리한다.
5. **지도와 보고서**: [report-template.md](references/report-template.md)를 읽고 `case.json`을 채운다. `scripts/render_case.py --case <case.json>`으로 키 없는 `report.html`, `map.html`, `map/vworld3d.html`을 생성한다. 템플릿은 출발점이며 과업에 맞춰 필요한 표·설계 분석을 추가한다. 직접적인 브라우저 3D는 `scripts/serve_case.py --root <케이스폴더> --env <env파일> --port <빈포트>`로 실행한다.
6. **검증·전달**: [quality-checks.md](references/quality-checks.md)의 데이터·계산·지도·모바일·키 검사 후 보고서와 근거를 묶는다. 완료한 조사, 조건부 판단, 사용자에게 요청 중인 자료를 최종 응답에 구분한다.

## 지구단위계획 의무 절차

- 토지이음 적용구역 확인 후 토지이음 고시, 관할 지자체 도시계획/고시공고, 광역지자체 공보 등 **공식 원문을 먼저 검색**한다. 필지주소·구역명·고시번호로 좁혀 검색한다.
- 자료가 있으면 지정용도·불허용도, 건폐율·기준/허용/상한용적률, 높이, 공동개발, 건축한계선/지정선, 전면공지, 차량출입구/금지구간, 공공기여·인센티브 조건을 함께 조사한다.
- **찾지 못했거나, 일부만 확보했거나, 적용 여부가 불분명하면 사용자에게 자료를 요청한다.** “없음”을 “계획 미적용”으로 처리하지 않는다. 결정조서만 있고 결정도나 시행지침이 없으면 그 누락 자료를 구체적으로 요청한다.
- 요청 예: “공식 검색에서 ○○구역의 결정조서는 확인했지만 최신 결정도·시행지침은 확보하지 못했습니다. 보유하신 지구단위계획 결정도, 시행지침, 변경 고시 PDF/HWP/DWG 또는 공식 링크를 보내주세요. 그동안 현황·대장 분석은 계속 진행하겠습니다.”
- 자료를 요청한 뒤에도 독립적인 현황·대장·지도·산술 비교는 진행한다. 답변 없이 누락 규제를 확정하거나 승인 가능한 출입구·건축선을 그리지 않는다. 결과에는 ‘자료 보완 전 예비검토’와 요청 항목을 남긴다.
- 공식적으로 미적용이 확인된 경우 그 근거를 기록하고, 사용자가 보유한 별도 관련 계획·고시가 있는지 한 번 확인한다. 없는 자료의 제출을 반복 요구하지 않는다.
- `district_plan.status`는 `verified`, `partial`, `not_found`, `unknown`, `not_applicable_verified` 중 하나로 기록한다. `verified`는 적용 규제에 필요한 누적 자료를 확보·대조했을 때만 사용한다. 검색 시도와 요청 여부를 `search_log`, `requested_from_user`, `missing`에 남긴다.

## 지도에서 지킬 구분

공식 도형(필지·지역·지구) / 공식 수치를 재구성한 참고선 / 아직 확보하지 못한 규제선을 구분한다. 좌표 근거 없는 출입 화살표나 금지선을 생성하지 않는다. 재구성 선에는 출처·방법·미확정 상태를 표시한다. 출입구가 미확정이면 별도 상태 카드로 보여준다.

브이월드 실제 3D를 연결하고 대상 필지로 이동한다. 배경 촬영/모델 시점과 대장 사용승인일의 차이를 설명한다. 2D 윤곽의 단순 높이 모형은 ‘참고 매스’로 표시하고 실제 3D 모델이라고 부르지 않는다. 연결 불가 시 미확인 사유와 2D 대체 보기를 제공한다.

## 예시·도구의 사용 범위

- [상봉동 예시 해설](references/example-sangbong.md): 실제 시행착오와 확인 수준, 재사용하면 안 되는 대상지 조건.
- `assets/examples/sangbong/`: 기존 전체 보고서, 지도와 근거자료. **예시 전용, 작성 당시 값**이다.
- `assets/case.schema.json`, `assets/blank-case.json`: 재사용 입력 구조. 미확인 값은 `null` 또는 명시적인 미확인으로 둔다.
- `assets/templates/`: 보고서·2D 지도·3D 뷰어 소스. 새 대상지 데이터를 분리해 주입한다.
- `scripts/package_skill.py`: 공유용 ZIP 생성과 인증키·개인 절대경로 점검. 사용자가 요청하지 않은 게시·업로드는 하지 않는다.

도구 이름이나 로컬 경로가 다른 환경에서는 사용 가능한 동등 도구를 사용한다. PDF/HWP·웹·브라우저 도구가 없을 때는 읽지 못한 자료를 읽은 것처럼 처리하지 않는다. 스킬 자체가 외부 게시나 메시지 전송을 허가하지 않는다.
