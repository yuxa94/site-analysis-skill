# 전달 전 확인

1. 대상지 주소/PNU와 지도 강조 필지가 일치하는가? 다른 주소의 토지이음 응답을 섞지 않았는가?
2. 지구단위계획 상태가 원문 확보 수준과 맞는가? 누락 자료를 사용자에게 실제 요청했는가? 최신 변경이 빠지면 확정 수치를 쓰지 않았는가?
3. 합계·건폐율·용적률·비율·세대수·주차를 재계산했는가? 0건·누락을 0이나 규제 없음으로 바꾸지 않았는가?
4. 좌표계·경위도 순서·다중 폴리곤/구멍을 유지했는가? 건축선·출입구가 근거 없이 생성되지 않았는가?
5. 실제 브라우저에서 레이어/확대/대상지 복귀/속성 조회를 조작했는가? 390px 전후 모바일과 데스크톱에서 가로 넘침·잘림·3D 컨트롤을 확인했는가? 사용한 임시 화면 크기를 복원한다.
6. 3D가 실제 지형·건물을 표시했는가? 연결 코드만으로 성공 선언하지 않는다. 사진 시점 차이와 참고 매스 구분, 미연결 시 사유가 있는가?
7. 로컬 파일 링크와 자료 출처가 열리는가? 3D는 로컬 서버·인터넷·사용자 키가 필요하다고 적었는가?
8. HTML·JS·JSON·ZIP에 실제 키·.env·개인 경로가 없는가? 실행 시 브라우저에 VWorld 인증값이 전달될 수 있음을 사용 안내에 적는다. ‘브라우저에서도 키가 숨겨짐’이라고 말하지 않는다.

`python3 scripts/package_skill.py --out <공유.zip> --env <키검사용env>`는 스킬 배포 검사를 한다. 다른 보고서 ZIP은 별도 폴더 allowlist로 만들고 키 검사를 수행한다. 모든 프로그램 생성 결과에는 `source_id`와 상태를 남긴다.
