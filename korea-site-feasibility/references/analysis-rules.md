# 분석 불변조건

## 사실과 해석

모든 핵심 수치에는 자료명·조회일·행/필드 또는 고시 페이지를 연결한다. 구분은 `confirmed`(원자료 확인), `calculated`(재현 가능한 계산), `assumption`(설계 가정), `unverified`(자료 미확보)다. 자료 충돌 표에 각 출처·기준일·채택 이유를 남긴다.

- 필지면적 / 사업대지 / 좌표 도형의 근사면적을 분리한다. 현재 필지와 과거 공동개발 토지 목록을 혼동하지 않는다. 부속지번0건으로 합필을 단정하지 않는다.
- 건폐율=건축면적÷대지×100. 용적률=용적률 산정 연면적÷대지×100. 전체 연면적을 용적률 분자로 쓰지 않는다.
- 동별 대장의 수를 물리적인 타워 수로 더하지 않는다. 별도 주차장·기계실 대장과 지하층을 확인한다.
- 포털에서 확인한 현재 실현 용적률을 새 일반 사업의 허용 용적률로 역산하지 않는다. 주거 유형·공공기여·임대 조건·인센티브 조건을 확인한다.
- 사용승인된 건물이 있으면 운영/변경/철거·재건축 시나리오를 구분한다.

## 현재 법령 확인

대상지 조례, 국토계획법·시행령, 건축법·시행령, 주택법·시행령, 주택건설기준, 주차장 기준과 개별 고시를 **작업 기준일의 공식 시행본**으로 조회한다. 현재 시행과 미래 시행을 분리한다. 예시 링크/시행일을 현재 것으로 간주하지 않는다.

검토 분야: 용도허용, 사업계획승인/건축허가, 건폐율·용적률·높이, 주거복합 비율, 세대수·주택 유형, 주차(면적/세대별/용도별/완화), 접도·건축선·대지 안 공지, 채광·일조, 피난·소방, 승강기·접근성, 조경·공개공지, 교육환경·철도·군협의, 굴착·지하안전, 공공기여. 근거 없는 일반적인 수치 나열 대신 대상지 적용성을 판정하고 불명확한 부분을 표시한다.

군 협의 해발표고와 건축물 높이, 철도보호지구와 계획 철도선, 건축한계선과 보도부속형 전면공지를 구분한다. 동일 공간을 이중 합산하지 않는다.

## 규모 시나리오

사용자가 요청한 용도 조합에 맞춘 비교안을 만든다. 대지×가정용적률, 주거/비주거 면적 배분, 전용효율, 세대 타입별 면적·세대수, 주차 산정근거를 보인다. 평균 전용면적만으로 면적구간별 주차 기준을 계산하지 않는다. 도시형생활주택의 유형/세대 한도는 최신 법령으로 검증한다.

상한 면적은 건축 가능 면적이 아니다. 램프·코어·피난·주동 배치 테스트를 하지 않은 수치는 ‘면적 예산’으로 표시한다. 수치상 잔여 용적률을 곧바로 증축 가능분으로 부르지 않는다. ‘적합’ 판단은 입력·적용 법규·계산·도면이 갖춰진 항목에 한정한다.
