# 지구단위계획 탐색·누락 자료 처리

## 탐색 범위

1. 토지이음의 **주소/PNU가 일치하는** 필지 화면에서 지구단위계획구역과 기타 촉진지구·정비구역·도시계획시설·건축선 여부를 읽는다. URL의 지번만 맞고 결과 주소가 다른 응답은 버린다.
2. 주소, 구역명, 확인한 고시번호로 토지이음 고시정보와 지자체 고시공고·공보·도시계획 공개자료를 검색한다. 광역/기초 지자체의 담당기관을 확인한다. 민간 블로그는 공식 출처를 찾는 단서로만 쓴다.
3. 최초 결정에서 최신 변경까지 고시 목록을 만든다. 고시마다 날짜, 변경 대상, 도서 목록, 실제 확보한 파일·페이지를 기록한다. ‘그 외 변경 없음’은 해당 직전 고시와의 관계이지 최초 결정의 모든 조건이 그대로라는 증명이 아니다.
4. ‘결정도 게재생략’, 담당부서 열람, 다운로드 실패 등은 **자료 존재와 파일 미확보**를 구분한다. 인증·캡차가 필요하면 사용자에게 정상 열람 협조를 요청한다.
5. 관련 공식 경로를 조사해도 확보할 수 없으면 검색을 무한 반복하지 말고 미확보 항목과 조사 경로를 설명하여 사용자에게 요청한다. 다른 분석은 계속한다.

## 최소 자료 목록

| 자료 | 확인 내용 | 없을 때 |
|---|---|---|
| 결정/변경 고시·조서 | 구역, 용도, 건폐율, 용적률, 높이, 변경 이력 | 사용자에게 원문/공식 링크 요청 |
| 결정도·종합결정도 | 획지, 공동개발, 건축선, 도로, 차량출입금지 | 위치를 임의 확정하지 말고 도면 요청 |
| 시행지침 | 권장/불허 용도, 인센티브, 대지 내 공지, 출입·형태 | 일반 조례로 대체하지 말고 지침 요청 |
| 지형도면·도시계획시설도 | 실제 규제선과 지적 중첩 | 좌표/축척/기준계 확인 요청 |
| 최종 승인·준공/교통처리 도면 | 현 건물의 출입구·주차·공공기여 | 공적 대장의 면적 정보와 분리 |

## 상태 결정

- `verified`: 적용구역과 현재 규제에 필요한 원문·변경 이력·도면을 확보하고 대조. 전 항목을 자동 적합으로 판정하는 상태가 아니다.
- `partial`: 일부 고시/조서만 확보, 결정도·시행지침 또는 누적 변경 누락. 누락 자료 요청 필수.
- `not_found`: 공식 검색을 수행했지만 원문 미확보. 미적용으로 결론 내리지 않고 자료 요청 필수.
- `unknown`: 대상지 동일성이나 적용구역 판정부터 불명확. 필요한 주소/공부/도서 요청.
- `not_applicable_verified`: 공식 자료로 해당 계획 미적용을 확인. 근거·확인일과 별도 고시 확인 질문 기록. 일반 법령·조례 및 다른 구역규제는 계속 검토.

도면상 출입금지선, 건축한계선, 건축지정선, 건축법상 건축선은 같은 개념이 아니다. 범례와 시행지침으로 구분한다. 스캔을 위치 보정할 때 기준점·좌표계·오차·참고도 표시를 남기고 법정 좌표라고 하지 않는다.
