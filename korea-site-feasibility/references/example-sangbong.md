# 상봉동 예시 / 2026-10-06 당시 조사

`assets/examples/sangbong/상봉동_116-49_기획설계_검토보고서.html`와 `상봉동_116-49_지도분석.html`은 이전 실제 결과다. 원본은 변경하지 않고 공유 예시로 복사했다. 예시의 실행 스크립트 대신 스킬의 일반 스크립트를 사용한다. 예시 전용 3D는 기존 뷰어이며 고정 주소를 가진다.

좋은 재사용 대상: 12개 분석 장의 흐름, 출처 표, 확인/가정/미확정 구분, 수치 산식, 지도 레이어, 원도 병렬 대조, 모바일 레이아웃.

재사용 금지: 상봉동의 주소/PNU/좌표, 2,027㎡, 과거 1,878.5㎡, 299세대·24층, 망우로3m, 건폐율60%, 상한960%, 높이80m, 청년주택 조건, GTX-B, 법령 링크의 시행일. 새 대상지에서 모두 재조회한다.

예시에서 토지이음 정상 재조회는 현재 면적2,027㎡로 대장과 일치했다. VWorld 토지특성1,878.5㎡는 불일치 값으로 남겼다. 2022-331호와2026-271호는 확보했으나2023-368·2026-213호 누적 변경 및 최종 결정도는 미확보였다. 새 스킬로 같은 과업을 진행하면 **누락된 결정도·시행지침·변경 고시를 사용자에게 요청해야 한다**.

3m 선은 고시 수치 재구성, 차량출입은 위치 미확정, VWorld3D는 과거 저층 모델, 청록79.9m는 참고 매스였다. 이 구분을 유지한다. 출처 원문은 예시의 sources 폴더에 있다.
