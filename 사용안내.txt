대지 현황 분석 skill
스킬 이름: korea-site-feasibility

공유 파일
korea-site-feasibility.zip (약 3.4MB)
ZIP 안에는 korea-site-feasibility 폴더 하나가 있습니다.

설치
1. ZIP을 해제합니다.
2. korea-site-feasibility 폴더를 받는 사람의 Codex 개인 skills 폴더에 넣습니다.
   기본 위치: ~/.codex/skills/
   CODEX_HOME을 별도로 쓰면 해당 경로의 skills/ 아래에 넣습니다.
3. 같은 이름이 이미 있으면 기존 수정 내용을 확인한 뒤 교체합니다.
4. 새 대화에서 $korea-site-feasibility를 호출합니다.

사용 예
$korea-site-feasibility로 [시·군·구 동 지번]을 분석해줘.
계획 용도는 공동주택·도시형생활주택·근린생활시설이야.
공공데이터포털·브이월드·토지이음을 확인하고 지구단위계획을 함께 조사해줘.
계획 자료가 없거나 일부만 확보되면 나에게 결정도·시행지침·변경 고시를 요청해줘.
2D·3D 지도와 법규·규모검토가 포함된 반응형 HTML로 작성해줘.

핵심 동작
- 주소/PNU/현재 건축물과 토지면적 대조
- 공식 지구단위계획 검색 → 누적 고시·결정도·시행지침 조사
- 미확보·일부 확보·적용 불명확 시 사용자에게 자료 요청
- 사실/계산/가정/미확인 구분
- 건축선과 차량출입 위치를 근거 없이 확정하지 않음
- 용도별 법규·규모·주차 검토 및 근거자료 정리
- 별도 입력 데이터로 반응형 HTML과 2D·실제 VWorld 3D 생성

구성
SKILL.md: 스킬 실행 절차
agents/openai.yaml: Codex 표시·호출 정보
references/: 지구단위계획, API, 분석, 템플릿, 검증 지침
assets/blank-case.json: 새 대상지 입력 양식
assets/case.schema.json: 데이터 구조
assets/templates/: 일반 보고서·2D 지도·3D 뷰어 템플릿
assets/examples/sangbong/: 이전에 작성한 상봉동 예시와 근거자료
scripts/: 새 케이스 생성, API 수집, 보고서 생성, 로컬 3D 서버, 공유 ZIP 생성

준비 사항
Python 3.9 이상, curl, 공식 웹/브라우저 조회 기능을 사용합니다.
자료에 따라 PDF/HWP/DWG를 읽을 수 있는 별도 도구가 필요합니다.
.env 파일은 받는 사람이 자신의 작업 폴더에 준비합니다.
필요 변수명: VWORLD_KEY, DATA_GO_KR_KEY
API 신청 범위·도메인 제한·인증 설정은 각 사용자 계정에 따릅니다.

2D HTML은 직접 열 수 있습니다. 실제 3D는 인터넷과 로컬 서버가 필요합니다.
API 키는 공유 ZIP에 없습니다. 실행 시 VWorld 인증을 위해 SDK와 브라우저에 전달됩니다.
상봉동의 면적·용적률·고시·규제는 작성 당시의 예시이며 새 대상지에 승계하지 않습니다.

검증 범위
스킬 구조 검사, 새 입력의 HTML 생성, 미확정 규제선 차단, 스크립트 삽입 문자 처리,
일반 템플릿의 2D 조회·3D 연결·참고 매스, 모바일 표시, 인증키·개인 경로 제외를 점검했습니다.
수집기의 모든 API·모든 지역·모든 인증 설정을 보증하지 않으며 상태·페이지를 확인해야 합니다.
