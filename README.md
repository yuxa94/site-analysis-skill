# 대지 현황 분석 skill

한국의 주소·필지를 **공공데이터포털, 브이월드, 토지이음, 지구단위계획**으로 조사하고, 현황·법규·기획설계 규모검토를 반응형 HTML 보고서로 작성하는 Codex 스킬입니다.

## 주요 기능

- 주소·PNU·필지면적과 현재 건축물·인허가 자료 대조
- 지구단위계획의 공식 고시·결정조서·결정도·시행지침·변경 이력 조사
- 자료가 없거나 일부만 확보되면 사용자에게 누락 도서 요청
- 건폐율·용적률·높이·용도·세대수·주차 등 기획설계 검토
- 2D 필지·규제 지도와 실제 브이월드 3D 뷰어
- 확인 사실, 계산, 가정, 미확인 사항을 구분한 보고서와 출처 정리

건축한계선·차량출입 위치는 근거 없이 확정하지 않습니다. 지구단위계획을 찾지 못했다는 이유로 미적용으로 판단하지 않습니다.

## 설치

이 저장소의 `korea-site-feasibility` 폴더를 개인 Codex skills 폴더에 넣습니다.

```bash
git clone https://github.com/yuxa94/site-analysis-skill.git
mkdir -p ~/.codex/skills
cp -R site-analysis-skill/korea-site-feasibility ~/.codex/skills/
```

같은 이름의 스킬이 이미 있으면 기존 수정 내용을 확인한 뒤 교체하세요. `CODEX_HOME`을 별도로 설정했다면 해당 경로의 `skills/`를 사용합니다.

표시 이름은 **대지 현황 분석 skill**, 호출 식별자는 **korea-site-feasibility**입니다.

## 사용 예

```text
$korea-site-feasibility로 [시·군·구 동 지번]을 분석해줘.
계획 용도는 공동주택·도시형생활주택·근린생활시설이야.
지구단위계획을 함께 조사하고 자료가 없으면 나에게 요청해줘.
2D·3D 지도와 법규·규모검토를 포함한 HTML 보고서를 작성해줘.
```

## 준비 사항

- Python 3.9 이상 및 curl
- 공식 웹·브라우저 조회가 가능한 실행 환경
- 사용자 본인의 브이월드·공공데이터포털 API 키
- 필요한 경우 PDF/HWP/DWG 열람 도구

작업 폴더의 env 파일 또는 환경 변수에 `VWORLD_KEY`, `DATA_GO_KR_KEY`를 설정합니다. **실제 API 키는 이 저장소에 포함되어 있지 않습니다.** API 신청 범위, 도메인 제한, 인증 설정은 사용자 계정에 따릅니다.

2D 지도는 생성한 HTML을 직접 열어 사용할 수 있습니다. 실제 3D는 인터넷과 전용 로컬 서버가 필요하며, 실행 시 브이월드 인증을 위해 키가 SDK와 브라우저에 전달됩니다.

## 구성

```text
korea-site-feasibility/
├── SKILL.md                  # 조사·분석·사용자 자료 요청 절차
├── agents/openai.yaml        # 표시 이름과 호출 안내
├── references/               # 데이터·지구단위계획·분석·검증 지침
├── assets/
│   ├── blank-case.json       # 새 대상지 입력 양식
│   ├── case.schema.json      # 입력 구조
│   ├── templates/            # 보고서·2D·3D HTML 템플릿
│   └── examples/sangbong/    # 상봉동 기존 보고서와 공공 근거자료
└── scripts/                  # 입력 생성·API 수집·HTML 생성·로컬 서버·패키징
```

세부 실행 방법은 [스킬 본문](korea-site-feasibility/SKILL.md), [템플릿 안내](korea-site-feasibility/references/report-template.md), [사용안내](사용안내.txt)를 참고하세요.

## 상봉동 예시의 활용

예시는 서울 중랑구 상봉동 116-49를 2026-10-06에 조사한 결과입니다. 문서 구성·출처 기록·지도 표현을 참고하기 위한 자료이며, 면적·용적률·건축선·높이·청년주택 조건·법령 시행일을 다른 대지에 적용하면 안 됩니다.

예시에서 미확보한 누적 변경 고시 및 결정도·시행지침은 그대로 미확인 상태입니다. 새 조사에서는 해당 자료를 찾아 대조하고, 확보하지 못하면 사용자에게 요청합니다. 예시 3D의 과거 건물 모델과 대장 높이 참고 매스도 실제 현황·정확한 건축형상과 구분합니다.

## 검증 범위

스킬 구조, 새 입력의 HTML 생성, 미확정 규제선 차단, 스크립트 삽입 문자 처리, 2D 조회·실제 3D 연결·참고 매스, 모바일 표시와 공유 패키지의 인증키·개인 경로 제외를 확인했습니다. 모든 지역·API 설정에 대한 전수 검증은 아니므로 응답 상태·페이지 수·대상지 동일성을 확인해야 합니다.

보고서는 기획설계 참고자료입니다. 최종 인허가 적합성은 최신 법령·조례·개별 고시·승인도면에 따라 검토합니다. 예시의 외부 공공자료는 각 출처의 이용 조건을 따릅니다.
